# TESL D: My Family - Description Builder

An interactive educational writing game where pupils learn step by step to describe a family member.

## Learning sequence
1. Choose a family member.
2. Choose two appearance details.
3. Choose two personality adjectives.
4. Choose an activity, job or extra detail.
5. Build correct sentences.
6. See the ideas combined into a short model paragraph.

The TESL D identity is the visual theme; the learning objective is **Writing: describing family members**.

## GitHub Pages
Upload `index.html`, `style.css`, and `game.js` to a GitHub repository. Enable Pages from the `main` branch and `/root`.

No external libraries are required.
